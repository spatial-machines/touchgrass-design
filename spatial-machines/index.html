SpatialMachines

A multi-agent GIS toolkit that turns spatial questions into maps, reports, web maps, and QGIS projects.

View project GitHub repo

agents / postgis / qgis / reports

Input

Ask a spatial question

Start with a practical mapping problem: a site search, route analysis, spatial summary, or public-data workflow.

Process

Specialist agents

GIS-focused agents coordinate data discovery, analysis, cartography, and delivery instead of treating maps as a generic chat output.

Output

Maps you can inspect

The goal is styled maps, reports, web maps, and project files that remain inspectable after the run is finished.

Why it belongs here

Touchgrass is mostly a place for photography, trips, and field notes now, but the mapping work still matters. Spatial Machines is the part of the project that happens while sitting at the computer: tools for understanding places before, during, and after being out in them.

Keeping it here preserves the old GIS thread without letting it dominate the whole site.
